# Perpl market marks

These eight SVG marks were verified and copied from the market-selection buttons of
[Perpl testnet](https://testnet.perpl.xyz/trade/BTC) on 2026-10-13:
BTC, ETH, SOL, MON, ZEC, LIT, PUMP and NEAR. Each mark was read from its own selected market header.

The original paths, fills, gradients, filters and viewBox are retained. Only runtime MUI classes,
ARIA attributes and em sizing were removed; dimensions are set to 40 × 40. These are static local
image files, without scripts, external references or injected markup. Third-party marks retain
their original colors and ownership. No generic icon collection is used.

The market map accepts only these reviewed local files. Unknown markets use a text fallback.
The marks identify the underlying markets; they do not imply ownership of spot tokens.
