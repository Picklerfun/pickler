Read root, runtime and parent plugin instructions. Core owns agent permissions; trading owns coherence/risk and infrastructure owns public transport. Do not construct models or signers here. Use public exports and close every acquisition reader. REST sessions retain twelve requests and one-second spacing; WebSocket is opt-in within the same Perpl plugin, with no fallback. Existing model tools remain read-only.
