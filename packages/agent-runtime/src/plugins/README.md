# Plugin composition

The core catalog owns identity, version, permissions, credential names and limits. The runtime
registry binds each ID to exactly one factory module. Directory names match existing persisted IDs.

Research factories produce only the injected read capabilities. Perpl composes bounded market-data
sessions. Paper and live execution factories return operator services, never model tools. Model
providers remain independent adapters. Provider IO belongs to infrastructure and financial rules
to `@pickler/trading`.

See [AGENTS.md](AGENTS.md) for extension requirements and the repository trading architecture guide.
