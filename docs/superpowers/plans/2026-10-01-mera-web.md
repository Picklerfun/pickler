# Mera on the web Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The web marketplace's chooser offers the Mera passkey wallet and the browser wallet; connecting signs in and asks for a username; Mera and Turnkey cannot meet.

**Architecture:** A second `SignerAdapter` beside the injected one. The Mera ceremony is a pure module with its parts injected, so it is tested with the vectors of `@pickler/mera-account` and no browser. The chooser's steps are a pure reducer. The API records the wallet kind in a column that already allows it. Spec: `docs/specs/mera-web-v1.md`.

**Tech Stack:** Next.js (client components), `@category-labs/mera` 0.2.0 and `viem` loaded on demand, `@pickler/mera-account`, Hono, `node:test` with `tsx`, ESLint flat config.

**Conventions:** worktree `/Users/Juvenal/Development/Pickler/pickler-mera-web`, branch `codex/mera-web`. Install with `npx -y npm@10.9.3`. Commit with `git commit -- <paths>`. Web tests cannot load a module that reads a value from `@pickler/api-schema` at load time (`apps/web/AGENTS.md`); keep the tested modules free of such imports.

## File structure

| Path                                                        | Responsibility                                                     |
| ----------------------------------------------------------- | ------------------------------------------------------------------ |
| `packages/core/.../identity/application/wallet-sign-in.ts`  | `verify` and `link` take the kind                                  |

| `apps/web/src/features/wallet/lib/mera-ceremony.ts`         | The ceremony: PRF → key → sign the server's message → zero         |
| `apps/web/src/features/wallet/lib/mera-availability.ts`     | Where the passkey wallet may be offered, and with what note (pure) |
| `apps/web/src/features/wallet/lib/mera-signer.ts`           | The browser `SignerAdapter`: prompts, memory, balance              |
