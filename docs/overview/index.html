📁 Templates

Clona el template que matchee tu caso de uso. Las skills pickler-overview-new y pickler-dev-new automatizan los dos flows más comunes — pídele a Claude "crea overview para X" o "registra este fix" y hace todo. Para el resto, clonado manual.

Cómo agregar un nuevo trabajo: los proyectos (multi-fase, schema changes) usan spec + plan en docs/superpowers/ + HTML overview en docs/overview/YYYY-MM-DD-<topic>.html. Los fixes y features de un solo PR usan un one-pager en docs/overview/dev/YYYY-MM-DD-<slug>.html (clona dev/_template.html). Ambos casos agregan entry al array window.DOCS de data/manifest.js.
