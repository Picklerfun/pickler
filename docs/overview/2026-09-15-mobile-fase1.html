01TL;DR

Resumen ejecutivo

Se construye la app móvil de Pickler en React Native / Expo (no Swift: ver §1). La fase 1 entrega login con passkey vía Mera → cuenta EVM en Monad Testnet → pantalla con balance de AUSD y MON → botón de faucet de AUSD, con build firmado listo para TestFlight. Sin backend, sin VPS.

03Decisiones clave

Decisión Por qué
Stack móvil: Expo SDK 57 / RN 0.86, TypeScript Mera solo tiene SDK TS (web, extensión, React Native); en Swift habría que reimplementar a mano la derivación PRF→EVM y el cliente de Perpl en 4 semanas. Jesús aceptó RN el 2026-09-15.
Auth: @category-labs/mera + react-native-passkey Es lo que pide el bounty; el passkey deriva la llave en el dispositivo, sin servidor de auth. Privy/Turnkey/Clerk descartados.
Red: Monad Testnet (chain 10143) AUSD existe en testnet con faucet; mainnet queda para después del demo.
Relying party (rpId): pickler.fun Zona en la cuenta Cloudflare "Pickler", Jesús es Super Admin. Cambiar el rpId después obliga a todos a registrar passkey de nuevo.
Bundle ID: fun.pickler.app Team Apple 2PBQJ37Q8W (el de Proflores).
Idioma de la app: Inglés Hackathon internacional.
Dispositivo: Solo iPhone, portrait Como Proflores v1.

Rulings en ejecución

  • Expo SDK 57 exige Xcode ≥ 26.4; se instaló Xcode 26.6 junto al 26.2, más el runtime de simulador iOS 26.5.
  • Mera no tiene SDK Swift (solo web/extensión/React Native); por eso la app es RN, con la misma derivación PRF→BIP-39→BIP-32 que el demo oficial.
  • Passkeys en simulador funcionan inscribiendo Face ID vía simctl spawn ... notifyutil.
  • expo run:ios --device pide el udid de hardware, no el de devicectl.
  • Cloudflare Pages no crea el CNAME del custom domain automáticamente; hay que crearlo a mano, y el wrangler.jsonc de Pages usa CLOUDFLARE_ACCOUNT_ID, no account_id.
  • La ASC API key de Proflores sirve para cualquier app del team; registrar el App ID y crear la app en App Store Connect se hizo a mano.
  • AUSD testnet tiene 6 decimales; el faucet requestFunds(address) da 10,000 AUSD y necesita MON para gas.
  • "Pickler" ya estaba tomado en App Store Connect; el registro se llama "Pickler Agents" con CFBundleDisplayName "Pickler".
