Task 2: Face ID at Pay, always

Owner decision 2026-10-13 (reverses the "Face ID stays at Ask" note): tapping "Pay {price} AUSD" always asks for Face ID — a fresh read of the stored passkey PRF (unlockStoredWallet() in src/wallet/wallet.ts) — before signTypedData, even when the wallet is already unlocked. The unlock at Ask for the quote (locked wallet) stays as it is.

  • In useAdviceAsk.confirm (src/hooks/useAdviceAsk.ts), the signing wallet comes from a fresh

    • unlockStoredWallet() call, never from the account's already-open wallet.

  • The fresh wallet's address must equal the account's address (case-insensitive); otherwise nothing

    • is signed and the flow shows an error (no payment, idle-style "nothing charged" semantics as any pre-signature failure).

  • No stored PRF → the same error path as today's unlock failure; Face ID cancelled → the same as

    • today (back to idle, nothing signed, next Ask gets a new key).

  • Session hygiene: if the account was locked, the fresh wallet becomes the account's (onUnlock, as

    • today). If the account was already unlocked, do not replace the account's wallet (other hooks hold it); sign with the fresh one and end its signing session (session.end()) once the signature is produced or the step fails.

  • The confirmation (src/screens/advice.tsx) always shows the Face ID icon on the Pay button and a

    • hint line while not busy (e.g. "Face ID confirms this payment."), not only when locked.

  • Tests in __tests__/advice-ask.test.ts (and the screen test if one covers the hint): with an

    • unlocked account, confirm() calls the fresh unlock exactly once before the signature, the signature comes from the fresh wallet, and the fresh session is ended; address mismatch → no signature, no request with X-PAYMENT; cancel → idle, no signature; the existing A1/A3 guards still pass. Seen failing first against the current code.

  • Docs: apps/mobile/AGENTS.md ("Where Face ID happens"), the audit (add Ruling A8: owner decision

    • 2026-10-13, Face ID also at Pay; restate A4/A7 and residuals 4–5 accordingly) and the overview docs/mobile/overview/2026-10-12-studio-agents.html (wherever it says Face ID stays at Ask). Read docs/mobile/AGENTS.md before writing there.
