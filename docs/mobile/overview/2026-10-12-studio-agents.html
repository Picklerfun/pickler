Studio agents in the app

A person in the iOS app lists the Studio agents that sell analyses, picks BTC or ETH, pays one fresh 24-hour analysis in AUSD (x402, split 65/35 by the splitter contract), waits for it and reads the result. The free history stays visible.

01TL;DR

Resumen ejecutivo

Product phase 3. The Agents tab gains a "Studio agents" section (priced agents from the marketplace). The advice screen shows the price, a BTC/ETH choice and an in-screen confirmation (agent, symbol, 65/35 split, recipient, total), signs a ReceiveWithAuthorization with the wallet, sends it as X-PAYMENT, polls the job and shows the result. The code is done on branch codex/mobile-studio-agents (not merged, not deployed, no TestFlight build). Acceptance against a real splitter is pending the operations of x402 spec §7 and fee-split spec §8. The section is off unless both PICKLER_API_URL and ADVICE_SPLITTER_ADDRESS are set at prebuild.

03Decisiones clave

DecisiónPor qué
The wallet signs ReceiveWithAuthorization to the splitter, never to the agentFee-split spec S2/S5/S6: one transaction pays 65% to the agent wallet and 35% to Pickler's treasury.
The confirmation lives inside the advice screen, like withdrawx402 spec §3.2: the same unlock rule as withdrawals.
One flow for the whole app, hoisted above the stacksNavigation remounts must not lose the Idempotency-Key, the signed header or the job id.
The free history stays free to readOnly a fresh analysis is paid.

Rulings en ejecución

  1. A1: a new Idempotency-Key per Ask; the key is reused only between the 402 and the paid retry of the same Ask. After settlement_failed the app never pays again.
  2. A2: the splitter address is build config (ADVICE_SPLITTER_ADDRESS); a 402 whose payTo differs is refused as untrusted.
  3. A3: the paid POST has its own 60 s deadline (the server waits up to 30 s for the receipt).
  4. A4: consent is the confirmation tap plus the withdraw unlock rule; the button reads "Pay {price} AUSD".
  5. A5: abandon() is also allowed from timeout.

Costs if wrong are in the audit: docs/mobile/superpowers/audits/2026-10-12-studio-agents-f1-rulings.md.

05Glosario

x402
HTTP 402 payment protocol: the server answers 402 with terms, the client retries with an X-PAYMENT header.
Splitter
PicklerAdviceSplitter, the contract that receives the payment and divides it 65% to the agent wallet and 35% to Pickler.
Studio agent
A marketplace agent with a price for its 24-hour BTC/ETH analysis.
