# PTS candidate catalog

This catalog is separate from the immutable `../pts` course bundle and from executable strategies.
Descriptor 0.1.0 remains a disabled draft. Independent 0.2.0 is experimental local paper only,
with its own v2 schema, policy and decision record. Neither appears in Studio/deployed registries.
Keep knowledge, candidate, documentation and implementation versions distinct. Published files
are immutable; changed criteria or parameters require a new candidate version. Documentation
corrections require their own version and description. Never add mandatory fields to the original
PTS contracts, fill unresolved parameters or rewrite source hashes. Validate the pinned bundle,
policy, schema and examples with the local baseline verifier. Documents here are in English;
original Spanish transcripts remain byte-identical in the course bundle.

Independent `pts-intraday@0.1.0` uses its own v3 descriptor/schema and native temporal decision
record. It is experimental local evaluation only; prior draft/basic/catalog schemas remain readable.
It never activates Studio or changes a published candidate in place.

Independent pts-intraday@0.2.0-fast.1 has a new v4 descriptor/schema and native temporal record. Preserve v1–v3 descriptors/policies/course bytes. It is experimental local evaluation only, without Studio selection or automatic public execution.
